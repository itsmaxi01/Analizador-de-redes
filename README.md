# Network Graph Analyzer

Simulador local de infraestructura de red implementado en Python 3.12+.

## Ejecutar pruebas

```console
python -m pytest -q
```

## Ejecutar la CLI

```console
python main.py
```

La sesión conserva la infraestructura entre instrucciones. `SALIR` termina la CLI y no forma parte de la gramática formal.
